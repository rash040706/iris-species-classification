# Iris Species Classification

## Objective
Prepare the Iris dataset for machine learning by splitting it into training and testing datasets.

## Tools Used
- Python
- Pandas
- Scikit-learn

## Dataset Information
- Total Samples: 150
- Training Samples: 105
- Testing Samples: 45
- Species:
  - Setosa
  - Versicolor
  - Virginica

## Conclusion
The dataset was successfully divided into training and testing sets, making it ready for model training and evaluation.
